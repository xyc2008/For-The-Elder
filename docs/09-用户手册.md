## 0. 给谁看，怎么对照屏幕读

### 0.1 给谁看

| 读者 | 看哪几节 |
| --- | --- |
| 拿到这台手机的人（本应用面向 55-65 岁刚退休的人） | 第 1 节到第 7 节。第 8 节也可以看——它写的就是「这台东西现在还不能替您做什么」 |
| 替长辈装应用、设置的人 | 第 1 节、第 5 节（设置）、第 7 节（常见问题） |
| 项目评审、将来接手的开发者 | 第 0 节、第 8 节、第 9 节（本手册与其它文档的对应关系） |

### 0.2 怎么对照屏幕读

本手册里出现在「」里的文字，都是从真实运行的界面上逐字抄下来的，**标点、空格、语气都没有改**。您可以在自己的手机上照着这些字去找：看到一样的字，就是同一个地方。

界面文字是中文，`uiautomator dump` 抓的是屏幕上**当前看得见**的节点。所以本手册里凡是提到「要往下滑一点才能看到」的地方，都是实测里真的没出现在首屏的（第 9 节记录了那次采集是怎么做的）。

### 0.3 第一条须知：它不会自己跳出来

这台东西和您手机上别的应用不一样，**它不会主动出现**：

- 没有通知，没有弹窗，没有提示音。装完之后，它一次都不会自己蹦出来。
- 它不会记您几天没来，也不会催您。
- 唯一「它先开口」的场合，是**您自己打开它的那一刻**：首页顶上会有一句话。就这一句，没有第二条。

所以这份手册要讲的不是「怎么操作」，而是**它在等什么**：它等的就是您想起来的时候打开一下。想不起来，也不会怎样——首页底下那句话是这么写的：

> 「今天没有要做的事，也没有要签到的项目。想到就打开看看，想不起来也不会怎样。」

这句话是屏幕上真实存在的（第 15 轮实测，首页最后一条文字）。它不是安慰话，是这台东西的行为描述：**没有每日任务、没有签到、没有进度条**，所以您不来的时候，它这边确实什么都没发生，也没有东西会「断」。

### 0.4 一页总览

| 页 | 怎么进去 | 它在这一页干什么 |
| --- | --- | --- |
| 引导（3 页） | 第一次打开时自动出现 | 问称呼、问字号、问要不要按您的作息说话。三页走完就不再出现。想再看一遍有两条路：设置页里**只读**的「再看一遍开头那几页」（一个设置都不动），或者会清回初始状态、一次全清的「清空全部数据」 |
| 首页 | 打开应用就是这一页 | 顶上跟您问一声好（或者安静地不说话），下面三个入口 |
| 说两句 | 首页点「跟常伴说两句」 | 您说一句，它把听懂的部分念给您听，问要不要记住 |
| 玩一会儿 | 首页点「玩一会儿」 | 八个小游戏，一局大概两三分钟，关掉就没了 |
| 设置 | 首页点「设置」 | 称呼、字号、作息、说话的时机、关于、重新来一遍（最后这块里还有一颗只读的「再看一遍开头那几页」） |

### 0.5 界面只在四页之间走

这台东西一共就这几个地方，没有更深的路，也不会迷路：

```
                    ┌──────────────┐
                    │   引导 3 页   │  只在第一次打开时
                    └──────┬───────┘
                           │ 第 3 页的两个按钮都往下走
                           ▼
        ┌──────────────────────────────────────┐
        │                首页                  │
        │  顶上：一句话（问好或安静）           │
        │  「跟常伴说两句」「玩一会儿」「设置」  │
        └───┬──────────────┬─────────────┬─────┘
            │              │             │
            ▼              ▼             ▼
      ┌──────────┐   ┌──────────┐  ┌──────────┐
      │  说两句  │   │ 玩一会儿 │  │   设置   │
      └──────────┘   └────┬─────┘  └──────────┘
                          │ 挑一个 → 开始 → 玩 → 结束
                          │ 规则页上往回走一步：「换一个游戏」
                          │ 结束卡上只有一条退路：「回去歇会儿」
                          ▼
                       回到首页
```

每一页的**左上角都有一个返回箭头**（它的读屏名字是「返回上一页」），点它回到上一页。所以任何一个地方走错了，往左上角点一下就回去了。

上面图里那句「引导 3 页：只在第一次打开时」从**第 47 轮**起有一个例外：设置页「重新来一遍」那块里有一颗**只读**的 **`再看一遍开头那几页`**，点它就把那三页原样再放一遍（只有这一条路，详见 §5.6）。它是只读的——**一个设置都不改**；第 1 次进来时要您动手的那两处（称呼框、字号单选）在重看时**点不动**，页上也会写一句 `这一页只是让您再看一遍。这里改不了，要改请回设置页。`

### 0.6 设置页没有「确定」按钮

设置页里除了两处删除要确认，**改什么都没有「确定」**——点一下就是选定了，立刻生效。屏幕上的原话是：

> 「点一下立刻生效，不用按确定。」

唯一的例外是称呼：那里有一个「保存称呼」按钮，因为称呼是打字输入的，需要您告诉它「打完了」。

## 1. 第一次打开：三页引导

第一次打开应用，会依次看到三页说明。**这三页只有这一次**，走完就不再出现（想再看一次，见第 5.6 节——**不用清空任何东西**：那里有一颗只读的「再看一遍开头那几页」，点它只把这三页重放一遍，称呼、字号、作息一个都不动）。

### 1.1 第一页：先把「不做的事」说清楚

**您会看到**（实测首屏文字，按屏幕从上到下的顺序）：标题「常伴」，副标题「一个懂节制的陪伴者」。

卡「它现在会做的」，一共 5 条：

> 「记得您希望被怎么称呼。」
> 「按一天里的时段，跟您问一声好；这会儿不合适就不出声。」
> 「按您的需要放大字，不用去改手机设置。」
> 「想说话的时候，跟它说两句。」
> 「手上闲不住的时候，有八个小游戏，不算分也不排名次。」

卡「它不会做的」，一共 3 条：

> 「不会向您推销任何东西。」
> 「不会催您、不会记您几天没来。」
> 「不会替您判断身体状况。」

下面还有一段小字：

> 「上面这些都在这一版里，不用再打开什么开关，它也不会弹窗通知您。想做点什么、或者什么都不做，都行。」

**点哪里**：底部一颗大按钮「我看看怎么用」。

**会发生什么**：翻到第 2 页。这时候还没有任何东西被保存下来——三页都走完才写。

**这一页的实测细节**：**第 18 轮已补上读屏说明**——这一页的表头现在挂着 `heading()`，还带一句**不显示在屏幕上**的状态说明「第 1 页，共 3 页」（`stateDescription`），读屏软件据此能念出「这是第几页」。第 15 轮 dump 时这一页的语义标签是 0 条，那句记录描述的是当时的状态，现已作废。第 18 轮的证据有两处：设备用例 `A11ySemanticsTest` 的「引导三页的表头是标题而且报得出第几页」（逐页断言这一句），以及装机走查 `build/screens18.log`——它 dump 出的可见文字里 `第 1 页`/`第 2 页`/`第 3 页`/`共 3 页` **全部不出现**，说明这句话只活在语义树里、没有画到屏幕上给所有人看。

### 1.2 第二页：怎么称呼您、字要多大

**您会看到**：标题「怎么称呼您」。

第一张卡「您希望被怎么称呼」，里面是输入框，提示字是：

> 「比如：老张、王老师」

下面一段小字：

> 「空着也行，以后在设置里随时能补。」

第二张卡「字的大小」：

> 「选一个看着最舒服的。下面这句话会立刻变成您选的大小。」

三个选项：「标准」「大一点」「更大」。

然后是一张预览卡，标题「您会先看到这样一句话」，里面的内容**是真的**——它当场按您选的字号，把今天会用到的第一句话算出来给您看。因为此时还没填称呼、也是第一次打开，实测看到的是：

> 「早上好」
> 「第一次见面，慢慢来。」

预览卡下面还有一句：

> 「字号预览就到这里，下面的按钮不受影响。」

**点哪里、会发生什么**：

| 点哪里 | 会发生什么 |
| --- | --- |
| 「标准」/「大一点」/「更大」 | 上面那句预览**立刻**变大变小，不用按别的。选哪个都行，随时能回来改（第 5.2 节） |
| 输入框 | 弹出键盘，可以打字。不知道写什么就空着 |
| 底部大按钮「下一步」 | 去第 3 页 |
| 底部小按钮「回去看上一页」 | 回第 1 页 |
| 左上角返回箭头 | 回第 1 页（和上面那颗是一样的作用） |

**这一页实测的一个细节**：「下一步」在 1080×2400 的屏幕上贴在底边（实测点击位置 y≈2329，屏幕高 2400），而「回去看上一页」在**首屏之外**，要往下滑一点才看得见。屏幕小一点、或者系统字号调大的手机上会更明显。这是现状，不是设计意图，记在这里免得您找不到那颗按钮。

**这一页不落盘**：在这页上打了称呼、换了字号，如果**在第 3 页之前退出应用**，这些都不会被保存，下次打开还是从第 1 页开始。这是实测过的行为（第 3 页才一起写下去）。

### 1.3 第三页：关于「它什么时候跟您说话」

**您会看到**：标题「想先跟您说件事」，小字「这一步得先问过您。」

卡「为什么要知道您什么时候用手机」：

> 「因为「该跟您说句话了」这件事得按您的作息来。常伴不看闹钟——有人六点就起了，有人九点才醒。知道您什么时候醒着、什么时候在歇着，它才不会挑您午睡的时候开口。」

卡「记在哪里、记多久」，一共 4 条：

> 「只记在这台手机上，不上传，常伴也不联网。」
> 「不读您看了哪个应用、跟谁聊了，也不要任何额外权限。」
> 「只保留最近 30 天，过期的自动删掉。」
> 「常伴从后台被划掉之后，那期间就记不到了。」

**点哪里、会发生什么**：底部两颗按钮。

| 按钮 | 会发生什么 |
| --- | --- |
| 「可以，按我的作息来」 | 打开作息采集，然后进首页。以后它按您自己的作息决定什么时候开口 |
| 「先不用」 | 不打开采集，然后进首页。**功能一样都能用**，只是它说话的时机改按普通人的作息猜 |

两颗按钮下面还有一句：

> 「两个按钮都能选。以后在设置里随时能改，也能一键把记下的东西全删掉。」

**要特别说清楚的一点**：这两颗按钮**都往下走**，都是正常选择。「先不用」不是取消、不是退出，更不会让应用少什么东西——它是「我不要这一项」的意思，选了之后应用照常问好、照常说两句、照常玩游戏。第 5.3 节讲怎么在设置里随时改。

**点哪里会回上一页**：这一页的返回只有左上角返回箭头（「返回上一页」），底部两颗按钮都往下走。

### 1.4 引导走完之后

三页走完，就直接是首页了。**以后每次打开应用，都直接进首页**，不会再看到这三页（第 15 轮实测：引导结束后，第 4 屏就是首页）。

## 2. 首页：打开就是这里

### 2.1 第一眼看什么

首页从上到下是四块：顶上的一句话（一张卡片）、两条主入口（整块可点的大卡）、一条次要入口（设置）、最后一段小字。第 15 轮采集到的首屏原文如下，**第 49 轮把两条主入口换成了大卡，这几句话一个字没改**：

> 「常伴」
> 「早上好」
> 「第一次见面，慢慢来。说话的时机，我先按普通的作息来。」
> 「告诉我您希望被怎么称呼」
> 「跟常伴说两句」「想说话的时候」
> 「玩一会儿」「手上想有点事的时候」
> 「您自己的节奏」
> 「设置」
> 「今天没有要做的事，也没有要签到的项目。想到就打开看看，想不起来也不会怎样。」

**第 49 轮改的是这两条主入口的样子，不是它们说的话**：此前首页是三个长得一样的入口行，看完分不出哪个是主干；现在「跟常伴说两句」和「玩一会儿」各是一张**整块可点的大卡**——左边一枚圆形徽章（说话是绿的、玩是暖的），右边一行大字加一行小字，「设置」仍旧是窄窄的一行，缩在「您自己的节奏」这个小标题底下。第 49 轮在模拟器上量到的数字：大卡高 **124.6dp**、宽 **371dp**，设置那一行高 **71.2dp**；卡片四边那条描边是**不透明**的 `#7E857F`，对卡片底色 **3.78:1**、对页面底色 **3.57:1**（WCAG 的 1.4.11 对「界定范围的边界」要求 ≥ 3:1）。为什么非要这条线：卡片填充色本身对页面背景几乎一样亮（1.0x:1），**界定这张卡范围的是那条线，不是底色**（`records/03` ADR-044）。徽章底色只用来分家，**区分不只靠颜色**——图标形状和文字说的都是同一件事，灰度下也一样分得清（WCAG 1.4.1）。还有一点跟手上感觉有关：整张卡都是可点区域，高 124.6dp，比一枚指尖宽得多。

顶上那句话是**两行**：第一行是问候语，第二行是补的一句话。问候语按**手机上现在的时间**算（早上好 / 上午好 / 中午好 / 下午好 / 晚上好 / 夜深了）；第二行在第一次打开那天是「第一次见面，慢慢来。」，以后会变成「已经认识 N 天了。」

**别被上面那个「早上好」弄糊涂**：采集时那台设备把时区设成了 `GMT`，当时是 07:31，所以它说「早上好」。它只看手机自己的时钟，不看别的。

### 2.2 顶上那句话会变——一共就四种样子

| 什么时候 | 您会看到什么 | 为什么这么写 |
| --- | --- | --- |
| 平常（该问好的时候） | 问候语 + 「第一次见面，慢慢来。」或「已经认识 N 天了。」；如果您记过日常，可能还有第三行（见 3.6） | 认得您、不装熟 |
| 刚跟您问过好，还没到下一次 | 「先不重复招呼了。」+「我在这儿。想说话随时说。」 | 刚说过就不再说一遍；同时把「想说话随时说」留着，安静不等于把门关上 |
| 您平常这个点已经歇着 | 「这会儿是您休息的时间。」+「我就不迎上来说话了，安静陪着您。您要是想说什么，随时说。」 | 不挑您休息的时候开口 |
| 作息还没摸清（没开采集，或记录还不够） | 问候语照旧，第二行后面多一句「说话的时机，我先按普通的作息来。」 | 说清它现在凭什么猜 |

**这是实测出来的，不是我推测的**：第 15 轮采集时，一开始打开应用，顶上写的是「早上好 …… 说话的时机，我先按普通的作息来。」；在同一台设备上玩了两个游戏、又进了两趟说两句页，回到首页时顶上变成了「先不重复招呼了。」+「我在这儿。想说话随时说。」——**中间没有改过任何设置**。所以那句话是真的会自己变。

**第三行（您记下的日常）只在它开口问好的时候才会跟着露出来**。安静下来的时候（上面第 2、3 两种）它不出现——就算您确实记过日常。理由写在了代码注释里：安静的时候还多补一句「您记下的那件事」，等于换个法子把话说出来了，安静语就不是安静语了。实测也是如此：记下一条日常之后回到首页，顶上仍然只有两行。

**安静下来的时候，底下还会多一行字，说清这个安静要持续到什么时候。** 上面四种样子里，只有第 2、3 两种安静会带上它（刚跟您问过好、和您平常这个点已经歇着）。这一行总是以 `下一次迎来说话最早在` 这几个字起头，念出来是这样的：

> 下一次迎来说话最早在 11:00 之后。

那句话里说到的时刻，如果落在第二天，中间会多一个「明天」——

> 下一次迎来说话最早在明天 07:00 之后。

**它说的是最早，不是保证。** 它的意思只是：在那之前不会再迎上来说话，而不是一到点就会来。本版本没有通知通道，所以一个提醒或到点的字眼都没写。

**它有时候干脆不出现。** 那一条时刻要是落在后天或更远，这一行就先不摆出来；而您自己说过「今天先安静一会儿」的时候，这一行也不摆 —— 您那句话不是一次待办，替它报一个时刻反而像在催您。

**这一行和您记下的那件小事不是同一行**：您记下的日常只在它开口问好的时候才露（见上一节），安静的时候不出现；这一行反过来，只在安静的时候才出现。

### 2.3 四个可点的地方——这就是您的「主动入口」

这一节是本手册最要紧的一节。

这台东西**不会自己跳出来**（见 0.3），所以「用上它」这件事只有一条路：**您自己打开它，然后在首页上挑一个**。首页上这四样可点的东西，就是全部的路：

| 首页上的那一样 | 长什么样 | 点进去做什么 |
| --- | --- | --- |
| 大卡「跟常伴说两句」 | 左边绿徽章，底下小字「想说话的时候」 | 您说一句，它把听懂的念给您听（第 3 节） |
| 大卡「玩一会儿」 | 左边暖徽章，底下小字「手上想有点事的时候」 | 八个小游戏，一局大概两三分钟，关掉就没了（第 4 节） |
| 「您自己的节奏」底下的第一行「今天先安静一会儿」 | 窄一行，行尾一颗小箭头 | 今天一天都不迎上来说话；再按一下就改回来（第 2.6 节） |
| 「您自己的节奏」底下的第二行「设置」 | 窄一行，行尾一颗小箭头 | 称呼、字号、作息、说话的时机（第 5 节） |

前两条是**整块可点**的：点卡片上任何一处都算点它，不是非要点在字上（第 49 轮量的：124.6dp 高）。后面两条是窄行，也一样整行可点（第 49 轮量到「设置」那一条 **71.2dp** 高；「今天先安静一会儿」用的是**同一个组件、同一套参数**，两行文字都没超过一行，所以同高）。

顺序可以自己核：第 60 轮的设备探针在首页语义树里读到两行的**文字节点同高、各 79 像素**——「今天先安静一会儿」y1757-1836、「设置」y1946-2025，x 都是 106，所以安静行确实压在设置行**上面**。同轮还有一次**真点**：手指落在那一行的文字中心 (503,1717)，当场就改了口（见 §2.6）。要留意的是，那 79 像素量的是**文字节点**，不是整行能点的范围；整行有多高这一条仍是按构造推的，没有单独量过。

这四样**不需要任何权限、不需要通知、不需要联网**。也就是说：只要您想用，随手就能用上，它这边没有任何前置条件要您先满足。

**为什么要把这件事单独说一遍**：一个不弹通知、不催人的应用，用它的责任就落在了「您记得有它」这件事上。这份手册能做到的，就是把「它到底能干什么」说清楚，这样您想起它的时候，知道打开来有东西可做——而不是打开看一下，又关上。

### 2.4 「告诉我您希望被怎么称呼」

没填称呼的时候，问候语下面会出现这一条：**「告诉我您希望被怎么称呼」**。它就是一句提醒，点一下会直接进设置页的称呼那一栏（第 5.1 节）。填过称呼之后这条就不再出现。它也是整行可点的。

### 2.5 首页没有「要做的事」

首页最后那句话是：

> 「今天没有要做的事，也没有要签到的项目。想到就打开看看，想不起来也不会怎样。」

这不是口号，是这一页真实的结构：首页上**没有任何待办、进度、连续几天、提醒**。您想不起来打开，它这边也不会有东西堆积起来等着您补。

### 2.6 今天不想被搭话：那条「今天先安静一会儿」

有时候您就是不想听它迎上来说那句问候——不是烦它，只是今天想清净一会儿。首页「您自己的节奏」那组里的**第一行**（在「设置」上面）就是为这件事准备的：**「今天先安静一会儿」**。

按下去，当场有三件事发生：

- 那一行自己改口，变成**「那就说话吧」**（再按一下就是改回来）；
- 顶上那次搭话换成一句安静的：**「好，那就先安静一会儿。」**，底下一行小字是「您说过今天先安静一会儿。我就不迎上来说话了，想说什么，随时说。」；
- 就算您确实记过日常（第 3.4 节那种），那条也不露面——安静的时候不补话。

再按一下「那就说话吧」，当场改回来。改回来的时候它会**重新判一次**：如果那会儿正好是您自己设的安静时段（见 5.4 节），顶上会是那句「先不重复招呼了。」，而不是问候——这是对的，不是没改回来。

**按它不算「您不理它」**。这一条要说清楚：平时它说了话而您没接，它会把下回说话的间隔往后推一点。您自己按下的静音**不进这个账本**——它只让今天不迎上来说话，**不**把下回说话的间隔往后推。

**它只管到今天为止**。它记的是「哪一天」，不是「开、关」：明天一到就自动恢复，不会因为忘了关就一直静下去。想过一个安静的明天，明天再按一下就是。

**还有一条要说清楚**：**这是第 61 轮的情况，第 62 轮已经改掉**。第 61 轮点完一句之后**首屏上看不到它给的回应**——点「我一直想学书法」，冒出来的「我听见的」那张卡会被顶到滚动区下沿以下，得往上滑才看得见。（这一句原来写的是「落在 y2822 附近、比下沿低约 485 px」，**那是探针里的换算值，不是直接量到的坐标**：探针 `probe61.py` 第 212 行按「说完了」这一行滑前滑后的位移反推出来的。读数时请按换算值看待。）**第 62 轮补上了这一步**：点完一句，页面会自己滚到回应卡那里，而且**一次回应只动一次画面**——带过去之后您再怎么滑，它都不会把画面拽回来。设备实测（第 62 轮，本机）：点「我一直想学书法」之后，脚本自己一次滑动都没发出去（`滑过 = 0`），回应卡七行整串都在滚动区里、且每一行整个落在区内；点故意听不懂的第 5 句「今天天气还行」，那张「这句我没听明白」的卡三行也整张落在滚动区里。**两条路都不用手动滑。** 下面 3.2 说的「前四句听得懂、第五句故意听不懂」，以及 3.3 说的点完看见什么，讲的都是页面自己滚过去之后看到的东西。

### 3.2 两种说话方式

**方式一：点现成的句子。** 「说一句」卡里、输入框下面是五句，实测是这五句：

> 「我一直想学书法」
> 「想学用手机」
> 「最近老是睡不着」
> 「帮我找找附近能下棋的地方」
> 「今天天气还行」

前四句它都听得懂。**第五句「今天天气还行」是故意留着听不懂的**——就是想给您看看「它说听不明白」长什么样，省得您以为是自己说错了。这五句只是引子，不是它能听懂的清单；它真正能听懂的说法比这五句多（见 3.7）。

**方式二：自己打字。** 点输入框，弹出键盘，打完之后点「说完了」。

> **这里有一条必须说清楚的**：用中文输入法一个字一个字打进去这条路，**到现在还没有真人试过**。开发过程中的测试是用测试代码直接把字送进输入框的，不是真的敲键盘。所以「我打字的时候它会不会认」这件事，目前只能算「应该没问题」，不能算「验过了」。见第 8 节。

### 3.3 听懂之后：它先问，记不记由您

它听懂之后，会在「说一句」卡下面多出一张卡「我听见的」（点完一句之后页面会自己滚到这张卡，**不用您手动滑**；见 3.1）。实测点「我一直想学书法」之后长这样：

> 「我听见的」
> 「您说的是：「我一直想学书法」」
> 「想做的事：书法」
> 「是从「一直想学书法」这几个字听出来的。」
> 「这件事要不要常伴替您记着？」
> 「愿意了解一下」「先不用」
> 「您点上面那两个按钮之前，常伴不会拿这件事给您推任何东西。」

三行说清了它听懂了什么：您的原话、它认出来的（类别 + 词）、以及它是从您哪几个字看出来的。**最后一行是它给出出处的地方**——您能核对它有没有认错。

它认得三类别，每一类的问法和按钮不一样：

| 它认出来的类别 | 它会问 | 两个按钮 |
| --- | --- | --- |
| 想做的事 | 「这件事要不要常伴替您记着？」 | 「愿意了解一下」/「先不用」 |
| 现在的状态 | 「这件事要不要常伴放在心上？」 | 「好，放在心上」/「先不用放心上」 |
| 想找人帮的事 | 「这件事要不要常伴记下来？」 | 「好，记下来」/「先不用记」 |

**这一问是闸门**：您不在上面点一下，它不会把这件事记下来。实测点「愿意了解一下」之后：

> 「好，记下了。您提起来的时候，常伴会接着听。」
> 「「书法」在下面「常伴记住的事」里，随时能删。」
> 卡里出现：「想做的事：书法」，旁边「记住了」，还有一颗「这件事不用记了」

它也不会因为您提了一句就到处拿去用。这件事的意义在代码和测试里都有对应的条文（`docs/01` 的 FR-06、`records/03` 的 ADR-011），手册里就说这一句：**它问过您之后才记，您点「先不用」它就不记。**

**第 66 轮起，这几颗相邻的按钮之间留的空隙从 8dp 抬到了 16dp（本机 21 px → 42 px）**：确认就留下、婉拒就不留、忘掉就删，这一族的按钮**长得一样宽、又挨在一起**，点错一次的代价是「我以为我拒绝了」，而屏幕上不会有任何提示告诉您点错了 —— 所以它们两两之间按误触余量留出 16dp。**按钮的文案一个字都没动**，改的只是它们之间的间距；同一段说明里那些**不能点**的正文行（标题、它认出来的证据、问法）仍旧留在原来的 8dp 上，好让这段话还读得成句。

### 3.4「常伴记住的事」：怎么删、怎么改主意

| 里面的状态字样 | 意思 | 旁边有什么 |
| --- | --- | --- |
| 「还没问过您」 | 听懂了，但还没问您（或问过您之后您还没答） | 等您在上面那颗按钮上点一下 |
| 「记住了」 | 您点了「愿意了解一下」这类按钮 | 「这件事不用记了」——点它**直接删掉，不再问一遍** |
| 「您说过先不用」 | 您当时点了「先不用」 | 一颗让您改主意的按钮：「我现在想了解一下」/「现在可以放心上」/「现在可以记下来」，下面还有一行小字「您要是改主意了，点下面这个按钮就行。」 |

最下面还有一颗「全部清空」，点它会问一次「确定要清空吗？」，确认了才全删。

**所以「删」是随时可以的**，一件一件删、或者一次全清。屏幕上那句话也是这么写的：「常伴只记这几件事，都在这台手机里，您随时能删。」

### 3.5 起点卡：它给的不是建议，是三步现在就能做的

如果您确认过一件「想做的事」（比如点了「愿意了解一下」），这一页会多出一张卡。**一次只摊开一条，不会一次铺开一大堆。**

实测（书法这件事）卡长这样：

> 「「书法」可以这样开始」
> 「这几步都是按「现在就能做、不用花钱、不用跑一趟」挑的。」
> 「写满一张纸　大概 10 分钟」
> 「挑一支顺手的笔　大概 5 分钟」
> 「照着喜欢的字描一遍　大概 15 分钟」

这三行是**收起来的**，点一下就摊开。实测点黑第二行之后：

> 「把家里能写字的笔都摊开，一支一支在纸上画一道，留下最顺手的那一支。」
> 「要准备：家里有能写字的笔才用得上；没有就先跳过这一条」
> 「这一步做完了」
> 「把这一步记成日常」

摊开的内容有三样：具体怎么做、**要准备什么**（这里写的是「家里有能写字的笔才用得上；没有就先跳过这一条」——不买东西、不跑腿）、以及两颗按钮。

点「这一步做完了」，它给一句回应（实测）：

> 「您刚做完的是：把家里能写字的笔都摊开，一支一支在纸上画一道，留下最顺手的那一支。。这件事是做完了的，不是想想而已。」

**这里曾经有一个真实的瑕疵**：这一步的回应里出现过两个句号（「那一支。。这件事」）。原因是这一步的正文本身以句号结尾，那句回应又接了一个句号。它是排版上的毛病，不影响用——**第 16 轮已经修掉了，并且配了回归用例**（`EncouragementTest` 会遍历全部 39 条起点正文，检查有没有双标点），所以现在您在手机上读到的是单句号。**照实写在这里，是因为这份手册里不该有「看上去没问题但其实有毛病」的地方。**

它给的三步不是随口说的：这件事一共覆盖 13 件事（书法、下棋、摄影、唱歌、戏曲、跳舞、养花、钓鱼、打太极、出去走走、做饭、看书、用手机），每件 3 条，都是按「现在就能做、不用花钱、不用跑一趟」挑的，耗时 5~20 分钟。

### 3.6 把它记成日常（您自己的节奏）

点「把这一步记成日常」，实测会问：

> 「把「挑一支顺手的笔」记成日常？记下来之后，您在这个时段打开应用，我会把它摆出来。您随时能删。」

然后给您四颗按钮，加一颗不记的：

> 「记在上午」「记在下午」「记在晚上」「想起来就做」「先不记」

选完之后，实测那句话变成：

> 「这一步已经记成日常了，记在上午。」

记下来的东西出现在下面的「常伴记着的日常」卡里。实测量到的是：

> 「常伴记着的日常」
> 「这些只在您打开应用的时候才出现，我不会另外吵您。不用记了就是直接删掉，随时可以再记一次。」
> 「上午」
> 「「把家里能写字的笔都摊开，一支一支在纸上画一道，留下最顺手的那一支。」」
> 「不用记了」

「不用记了」是**直接就删**，不再问一遍。这张卡空的时候写的是：「现在还没有。您在上面某一步上点「把这一步记成日常」，它就出现在这里。」

**一件实测过的、值得先知道的事：离开这一页就回到原样。** 实测过程是这样的：走到「要不要记成日常」这一步，回首页，再回到说两句页——那个问句、刚才那句回应、以及摊开的那一行，**全都收了回去**。只有您真的点了一颗时段按钮，才会留下记录。所以在这一页上随手点开看看，不会留下任何东西。

**记下的日常在首页怎么出现**：只有在它开口问好的时候，首页会多出第三行（原话是「您自己记下的一件事：……想做就做，不做也没关系。」）。安静语里不出现（原因见 2.2）。实测也是这样：记下那条日常之后回到首页，顶上仍然只有两行，因为当时正好在安静语状态——**记录在，只是没露在首页上**，回说两句页就能看到它好好地在那儿。

### 3.7 它只听得懂它学过的那几种说法

它认三类：想做的事、现在的状态、想找人帮的事。每一类背后是一张写好的词表，不是猜的、也不是联网问来的——它**没有联网**（屏幕上就是这么写的）。

所以有一件事要请您有个准备：**您说得跟词表不一样的时候，它可能听不懂**。听不懂的时候它会明说，卡「这句我没听明白」上面会写：

> 「没关系，换个说法也行，或者点上面别的句子。」
> 「没听懂的时候，常伴不会随便找个话题接着聊。」

这两句里说的「上面别的句子」，指的就是那五句现成的话。它在回应卡的**上方**：第 61 轮把五句从页尾搬进输入框那张卡之后（`records/03` 的 ADR-056 决定四），方位词跟着一起从「下面」改成了「上面」——**一字之差说的是方向，方向错了等于把人指反**。

它不会装懂，也不会听不懂就换个别的话题跟您接着聊——这一点是刻意这么做的，理由和条文在 `docs/01` 的 FR-04 与 `records/03` 的 ADR-010（用词表、不上模型）。

## 4. 玩一会儿

### 4.1 先挑一个

首页第二个入口是「玩一会儿」，点进去先到一页叫 **`玩一会儿`** 的挑选页。页上写着：

> 挑一个
> 点一个进去，里面会说怎么玩。

下面是大卡片，一张一个游戏（`PlayScreen.kt:104-105`：一张卡一个目录项，卡上只有名字，`PlayScreen.kt:127-128`）。这一版的顺序（**前四张**是逐轮在设备上实测到的屏幕位置；第 48 轮新增的第五张、第 144 轮新增的第六张、第 148 轮新增的第七张和第 158 轮新增的第八张**都没有实测位置**，依据是源码里目录的排列次序 `PlayCatalog.kt:41-46`——它们就排在最后）：

| --- | --- | --- |

### 4.2 找出一样的

进去先是一张开场卡，写着怎么玩：

> 格子里有 16 个字，其中两个是一样的。把这两个找出来。点错了也不要紧，再看看别的。

点「开始」以后是 16 个格子的牌面。这些格子里的词都是过日子会见到的东西，实测牌面用到的 20 个词是：

> 桔子 / 苹果 / 白菜 / 豆腐 / 茶壶 / 蒲扇 / 毛衣 / 布鞋 / 象棋 / 毛笔 / 藤椅 / 凉席 / 算盘 / 棉被 / 雨伞 / 桂花 / 月饼 / 核桃 / 花生 / 石榴

顶上写着 **`找出一样的那两张`**，就是这一局要做的事。

点错的时候，它说 **`不是它，再看看`**（不报错、不扣分、不结束，接着点就是）。点对了，两张一样的都收下，这一局结束，卡上写：

> 那两张「白菜」都找到了。（这里的「白菜」是您这一局真正碰到的那两张）
> 这一局只在屏幕上，关掉就没了。

**它不报用时。** 找一样的这一局完了就完了，没有秒数，没有最好成绩。这是和下面那个游戏不一样的地方，不是漏了。

### 4.3 舒尔特方格

开场卡：

> 格子里是打乱的 1 到 25，按从小到大的顺序挨个点一遍。点错了也不要紧，接着点就是。

牌面是 25 个格子，顶上写着 **`现在点 N`**——N 会跟着您点到哪儿一起变，所以您随时知道下一步该点哪个数，不用自己记。

两种点错，它说的话不一样：

| 您做了什么 | 屏幕上的话 |
| --- | --- |
| 点了顺序靠后的数 | `这个还在后面，不急` |
| 点了已经点过的格子 | `这个已经点过了，换一个` |

点完 25 个，这一局结束，卡上写：

> 25 个都点到了。这一局用了 1 分 39 秒。（这一句里的秒数是您这一局的真实用时）
> 用时只在这里显示，关掉就没了。

**舒尔特方格会报用时，但只在结束卡上出现一次**——它不进任何排行榜，不存进手机，关掉就没了。这是八个游戏里仅有的三个「会出数字」的地方之一（另外两个是第 4.8 节的「倒着点」与第 4.9 节的「单双数」，报的也都是同一句「用时只在这里显示，关掉就没了。」），也是刻意留的：它让您自己心里有个数，但不变成跟人比的东西。

### 4.4 算一算

开场卡：

> 从 100 开始，每次减掉 7。每题有三个数，把对的那个点出来。点错了也不要紧，再看看别的。

这一页会把承诺也写在卡上：**`一局大概 3 分钟就完了。不用计时，也没有分数跟谁比；慢一点也不要紧。`**

点「开始」以后，一次只出一题。题面长这样：

> 100 减 7 是多少？

下面三个数字，只有一个是对的。做对一道，题面就换下一道：

| 第几道 | 题面 | 对的数 |
| --- | --- | --- |
| 1 | `100 减 7 是多少？` | `93` |
| 2 | `93 减 7 是多少？` | `86` |
| 3 | `86 减 7 是多少？` | `79` |
| 4 | `79 减 7 是多少？` | `72` |
| 5 | `72 减 7 是多少？` | `65` |

点错的时候它只说 **`不是它，再看看`**——题面不动，也不结束，接着点就是。点对了，那句话自己就没了，直接换上下一道题。

5 道做完，这一局结束，卡上写：

> 5 道都算好了。
> 这一局只在屏幕上，关掉就没了。

**算一算、找出一样的、找一个不一样的、记一记和找同类都不报用时**，能报用时的只有上面那个舒尔特方格和第 4.8 节的「倒着点」。这里连「花了几秒」都不提，结束卡上只有一句「5 道都算好了。」

### 4.5 记一记

开场卡：

> 牌都盖着。点一张翻一张，两张一样就收起来，不一样就点一下盖回去。

这一页也把承诺写在卡上：**`一局大概 3 分钟就完了。不用计时，也没有分数跟谁比；慢一点也不要紧。`**

点「开始」以后是 **12 张牌**，4 列 3 行摆开。每一张翻开之前，格子上写的都是 **`盖着`**——不是问号。这句话是给听屏幕的人留的：读屏软件把问号一个个念成「问号」，十二张牌就是十二声「问号」；念「盖着」念出来是「盖着，第二行第三列」，正好是您要知道的那件事（`records/03` ADR-038）。

顶上写着 **`一次翻两张，一样的配成一对`**，就是这一局要做的事。

点开的两张不是一对的时候，它说 **`不是一对，点一下接着找`**。这里跟另外六个游戏不一样：**它不会自己把牌盖回去**，得您在牌上点一下，那两张才一起合上。第 41 轮在装好的 APK 上实测过这一条：点一张正摊着的牌，**两张**一起盖回去（`build/screens41.log:157`）——「点哪张只盖哪张」那种做法被那次走查当场判死。

牌面用的字和「找出一样的」是同一批（见 4.2 那二十个字）：每次从里面随机挑 6 个，每个写两张，再打乱位置，所以一局里**恰好六对**，不会出现「两张像是一对却配不上」的牌。挑哪六个每局都不一样，也不存进手机。

六对都配上了，这一局结束，卡上写：

> 6 对都配上了。
> 这一局只在屏幕上，关掉就没了。

**它不报用时。** 也没有翻牌次数、没有错误次数、没有分数——点错只换一句提示，别的什么都没动。

这个游戏原本是被判「顺延」的，理由是「第一张翻开来停多久再盖回去」得让代码记时间。第 41 轮把这条理由推翻了：**盖回去由您点一下驱动，不由表驱动**，于是它一秒都不用跟时间打交道（`records/03` ADR-038）。

### 4.6 找同类

开场卡：

> 格子里混着几样东西。上面说要找哪一类，就把那一类都点出来；点错了也不要紧，再看看别的。

点「开始」以后，盘面上混着**三样东西**（每一局从五类里随机挑三类），每类四个词，一共 **12 张**格子，四列摆开。顶上写的是这一局要找的那一类，句式为 **`把「水果」都点出来，一共 4 个`**（`PlayVoice.kt:94`，「水果」换成这一局真正抽到的那一类——这一类的名字是摆在格子上一起定下来的，不是另外查表）。

五类分别是 **水果 / 蔬菜 / 穿的 / 厨房里的 / 文具**，每类四个两字词（`KindWords.kt:26-32`）。挑哪三类、哪一类当目标、每个词摆在哪一格，每一局都不一样，也不存进手机。

点对一格，那一格**压暗**、就此了了，不用再点它。点错的时候它说 **`不是它，再看看`**（跟找一样的同一句，出处是 `PlayGame.kt:28`）——盘面一行都不动，接着点别的就是。已经点过的那一格再点一下，它说 **`这个已经点过了，换一个`**（`PlayGame.kt:22`）。

要找的那一类四格都点出来，这一局结束，卡上写：

> 4 个都点出来了。
> 这一局只在屏幕上，关掉就没了。

**它不报用时。** 也没有点错次数、没有分数——点错只换一句提示，别的什么都没动（`SameKindRound` 里没有一个能记下错了几次的字段）。

有两处细节是刻意定的，条文在 `records/03` ADR-043：

- 点对了的格子**不留高亮**。这一格只有「压暗」和「原样」两种样子（`SameKindRound.markOf`），不用「选中了还没成事」那种标记：这个游戏没有中间态，点中当场就了了，留个高亮反而会让您以为那一格还得再点它。
- 目标那几格是**摆盘的时候记下来的**，不是点的时候按字去反查类别。反查的做法在两类词万一有重字的时候，会把不相干的格子一起算进去，于是一局永远也完不成。

**诚实交代**：这一节的每一句都出自源码（`SameKind.kt`、`KindWords.kt`、`PlayVoice.kt:94/118/130`），**第 48 轮没有做装机走查**——所以这一页在屏幕上摆在哪儿、四列摆开在大字号下会不会换行，本轮**没有实测**。结束卡上「4 个都点出来了」这句的句式是从 `PlayVoice.kt:118` 逐字推出来的（把句中的数目当作 4），**没有在设备上读到过**。

### 4.7 找一个不一样的

第六个游戏叫 **`找一个不一样的`**。开场卡上写（`OddOne.kt:45-46`）：

> 格子里大部分是一样的东西，只有两个跟别人不一样；把这两个都点出来就完了。

进去之后顶上那句是 **`有两个跟别人不一样，都点出来`**（`PlayVoice.kt:98`）。

盘面是 **12 个格子、一行 4 个**（`OddOne.kt:34`、`OddOne.kt:40`）。一局里**恰好有 2 格**跟别人不一样（`OddOne.kt:36`），其余十格是一模一样的东西。点对了的那一格**压暗**、就此了了，不用再点它（`OddOne.kt:103-104`）。点错的时候它说 **`不是它，再看看`**（`PlayGame.kt:28`）——盘面一行都不动，接着点别的就是。已经点过的那一格再点一下，它说 **`这个已经点过了，换一个`**（`PlayGame.kt:22`）。

两个不一样的都点出来，这一局结束，卡上写：

> 那两个不一样的都找到了。
> 这一局只在屏幕上，关掉就没了。

**它也不报用时。** 也没有点错次数、没有分数——规则页上那句是一局大概 1 分钟（`OddOne.kt:48` 那个估时 60 秒折算来的，`PlayVoice.kt:141`），说的是「大概多久」，不是倒计时，屏幕上也不会催您。

有两处细节是刻意定的，条文在 `records/03` ADR-121：

- 点对了的格子**不留高亮**。这一格只有「压暗」和「原样」两种样子（`OddOne.kt.markOf`），不用「选中了还没成事」那种标记：这个游戏没有中间态，点中当场就了了，留个高亮反而会让您以为那一格还得再点它。
- 哪两格是不一样的那两个，是**摆盘的时候记下来的**，不是点的时候按样子去数。数样子的做法在两类词万一撞脸的时候会把不相干的格子一起算进去，于是一局永远也完不成。

**诚实交代**：这一节的每一句都出自源码（`OddOne.kt`、`PlayVoice.kt:98/123/136`、`PlayGame.kt:22/28`），**第 144 轮没有做装机走查**——所以这一页在屏幕上摆在哪儿、四列摆开在大字号下会不会换行，本轮**没有实测**。结束卡上「那两个不一样的都找到了。」这句的句式是从 `PlayVoice.kt:123` 逐字推出来的，**没有在设备上读到过**。

### 4.8 倒着点

第七个游戏叫 **`倒着点`**。开场卡上写（`ReverseGrid.kt:45-48`）：

> 格子里是打乱的 1 到 25，这回从大到小点：25、24、23……挨个点一遍。点错了也不要紧，接着点就是。

进去之后顶上那句是 **`现在点 N`**（`PlayVoice.kt:93`）——第一步是 **25**，往后越点越小，点完最后一个 1 就结束。

**盘面和舒尔特方格（第 4.3 节）一模一样**：5 行 5 列、25 个格子（`ReverseGrid.kt:40`、`ReverseGrid.kt:43`），每一局都重新洗牌，所以数字摆在哪儿局局都不一样（`ReverseGrid.kt:62-66`）。两局的差别只在先后：舒尔特方格从小到大点，这一局从大到小点。它就是给这个问法留的——**换个方向，您还做不做得到**。

两种点错，它说的话跟舒尔特方格**完全一样**（`PlayGame.kt:22`、`PlayGame.kt:25`）：

| 您做了什么 | 屏幕上的话 |
| --- | --- |
| 点了顺序还轮不到的格子 | `这个还在后面，不急` |
| 点了已经点过的格子 | `这个已经点过了，换一个` |

这两句是按「顺序」说的，分不出正着还是倒着，所以倒着点的时候照样读得通：25 点过了再点 25，说 `这个已经点过了，换一个`；轮到 20 之前去点 20，说 `这个还在后面，不急`。点错不用改，接着点就是。

点完 25 个，这一局结束，卡上写：

> 25 个都点到了。这一局用了 1 分 39 秒。（这一句里的秒数是您这一局的真实用时）
> 用时只在这里显示，关掉就没了。

**它跟舒尔特方格一样报用时**，也跟舒尔特方格一样只在结束卡上出现一次——不进排行榜、不存进手机、关掉就没了。这一版八个游戏里会出数字的就这三处（另外两处是上面第 4.3 节那一段，与下面第 4.9 节那一段）。

规则页上那句话是一局大概 3 分钟，说的是「大概多久」，不是倒计时，屏幕上也不会催您（估时写在 `ReverseGrid.kt:45-52`，折算是 `PlayVoice.kt:81-82` 做的）。

**诚实交代**：这一节的每一句都出自源码（`ReverseGrid.kt`、`PlayVoice.kt:93/118/135`、`PlayGame.kt:22/25`、`PlayCatalog.kt:45`），**第 148 轮没有做装机走查**——这一页在屏幕上摆在哪儿、五列摆开在大字号下会不会换行（跟第 4.3 节的盘面是同一个），本轮**没有实测**。结束卡上那句报用时的结束语（跟第 4.3 节那一句同一个句式）是从 `PlayVoice.kt:118` 逐字推出来的，**没有在设备上读到过**。

### 4.9 单双数

第八个游戏叫 **`单双数`**。开场卡上写（`OddEvenGrid.kt:56`）：

> 格子里是打乱的 1 到 25。先点单数：1、3、5……一直到 25；再点双数：2、4、6……一直到 24。点错了也不要紧，接着点就是。

进去之后顶上那句还是 **`现在点 N`**（`PlayVoice.kt:93`）——差别在于**方向会变一次**：第一步是 **1**，顺着单数往上，1、3、5……一路点到 25；点完 25 这一局**还没完**，它回到 **2**，再从双数往上点到 24。数一下：单数十三个、双数十二个，加起来正好 25（`OddEvenGrid.kt:43`、`OddEvenGrid.kt:50-51`）。

**盘面和舒尔特方格（第 4.3 节）、倒着点（第 4.8 节）一模一样**：5 行 5 列、25 个格子（`OddEvenGrid.kt:40`），每一局都重新洗牌，所以数字摆在哪儿局局都不一样（`OddEvenGrid.kt:69-73`）。三局的差别只在先后：舒尔特方格从小到大点、倒着点从大到小点、这一局**分两拨**点。它考的是另外那两局考不到的一件小事——**换一条规矩，您还接得上吗**：25 点下去的那一下，1 就在屏幕上，手最容易往那儿去。

两种点错，它说的话跟舒尔特方格**完全一样**（`PlayGame.kt:22`、`PlayGame.kt:25`）：

| 您做了什么 | 屏幕上的话 |
| --- | --- |
| 点了还没轮到的那一拨里的格子 | `这个还在后面，不急` |
| 点了已经点过的格子 | `这个已经点过了，换一个` |

这两句只说「先后」，不说「先后是按什么排的」，所以分两拨之后照样读得通：单数那一拨还没点完就去点 2，说 `这个还在后面，不急`；点过的格子再点一次，说 `这个已经点过了，换一个`。点错不用改，接着点就是。

点完 25 个，这一局结束，卡上写：

> 25 个都点到了。这一局用了 1 分 39 秒。（这一句里的秒数是您这一局的真实用时）
> 用时只在这里显示，关掉就没了。

**它跟舒尔特方格、倒着点一样报用时**，也跟那两局一样只在结束卡上出现一次——不进排行榜、不存进手机、关掉就没了。这一版八个游戏里会出数字的就这三处（另外两处是第 4.3 节与第 4.8 节那两段）。

规则页上那句话是一局大概 3 分钟（`OddEvenGrid.kt:58` 的 `longestSeconds = 180`，折算是 `PlayVoice.kt:81-82` 做的），说的是「大概多久」，不是倒计时，屏幕上也不会催您。

**诚实交代**：这一节的每一句都出自源码（`OddEvenGrid.kt`、`PlayVoice.kt:93/118/135`、`PlayGame.kt:22/25`、`PlayCatalog.kt:45`），**第 158 轮没有做装机走查**——这一页在屏幕上摆在哪儿、五列摆开在大字号下会不会换行（跟第 4.3 节的盘面是同一个），本轮**没有实测**。结束卡上那句报用时的结束语（跟第 4.3 节那一句同一个句式）是从 `PlayVoice.kt:118` 逐字推出来的，**没有在设备上读到过**。

### 4.10 八个游戏共有的规矩

不管玩哪个，结束卡上只有一个按钮：**`回去歇会儿`**。它的意思是回到**首页**——不是回到挑选页，更不是「再来一局」。这一步往后退一整层，把「玩一会儿」连同挑选页一起收起来（第 23 轮对着代码核过：这个按钮调的就是页面自己的返回，回的是首页；这里原先写着「回到挑选页」，写反了，已改正）。

这一版在「玩一会儿」里只有一处岔路：**规则页上，除了 `开始`，下面还多一条 `换一个游戏`**（第 23 轮加的）。它的意思是这一个不想玩、回去挑别的；点它直接回到挑选页，回到那一步什么都还没开始（这一局压根还没摆出来），所以退回去不丢任何东西。这条路**只开在规则页**：

- 玩到一半不摆它——那一屏每一格都在等人点，多一个按钮就是多一次「这个是不是要我点」；在玩的一局的退路是顶上那个返回。
- 结束卡上不摆它——那一屏只允许有一个按钮，而且必须是**离开**这一页的那个。

八个游戏刻意都没有下面这些东西（这一版是真的没有，不是藏起来了）：

- **没有倒计时 / 没有时间条**。屏幕上不会催您。
- **没有「还剩几个」的进度提示**。您想知道点到哪儿了，看顶上那句 `现在点 N` 就够了。
- **没有「再来一局」按钮**。想再玩，从结束卡回首页、再进一次；想换一个游戏，规则页上就有 `换一个游戏`（见上面 4.10 那段）。
- **没有保存、没有上传、没有和别人比**。这一局只在屏幕上，这句写在结束卡上，也是真的：玩一局不会往手机里写任何东西（`records/04` 有对应的设备验证记录）。
- **没有分数、没有等级、没有奖励**。

为什么故意做成这样，条文在 `records/03` 的 ADR-011 / ADR-012，需求侧在 `docs/01` 的 FR-06 一带。

## 5. 设置

首页第三个入口是「设置」。这一页是这一版里最长的一页，第 15 轮实测能在屏幕里读到 30 条文字。它分成六块，从上往下是：怎么称呼您 / 字的大小 / 作息数据 / 说话的时机 / 关于常伴 / 重新来一遍。

### 5.1 怎么称呼您

一行标题 **`怎么称呼您`**，下面一个输入框，框里灰色的例子写着 **`比如：老张、王老师`**。填完按 **`保存称呼`**。

按完不会有对话框弹出，按钮下面立刻多出一行小字：框里填着名字时写的是 **`称呼已保存。`**，框清空之后再按，写的就是另一句（见本节末尾）。它**不会自己走掉**——您在框里再动一下（比如改一个字），它就撤了；离开这一页再回来，它也不在了。输入框下面还常驻着一行说明：

> 把这里清空再按上面那颗按钮，就等于去掉称呼。

清空之后再按一次保存，按钮下面那行小字就换成了另一句：**`称呼已经去掉了，以后只问候，不带称呼。`**——它说的就是这件事本身。称呼去掉之后回到首页，「怎么称呼您」那行入口会重新出现，等您想填的时候再填；它跟您说话时就只问候，不带名字了，不是不认您了。

### 5.2 字的大小

**`字的大小`** 下面三颗按钮：**`标准`** / **`大一点`** / **`更大`**。点一下立刻生效，页上就这么写的：

> 点一下立刻生效，不用按确定。

点完之后，三行按钮**下面**会出现一行小字：**`字号已改成「大一点」。`**（跟着您点的那一档变字）。它和上面称呼那条一样不自己走掉；再点另一个档位，它就换成新的那一句——同一处只留一条，不会越积越多。

**重要的一条**：这里的字号和手机系统自己的字号是**叠在一起**变大的，不是二选一。页上也写着这一句：

> 这里的字号会和手机系统的字号叠在一起变大。

所以如果您已经把手机的字体调大了，再在这里选「更大」，字会比您预想得还大——这是好事还是坏事看人，但它是个事实，写在这儿。

### 5.3 作息数据

这一块先显示一行状态，一共四种样子（前三种是第 15 轮实测到的，第四种是源码里另一支、第 90 轮才补进这张表）：

| 屏幕上的话 | 意思 |
| --- | --- |
| `正在看这台手机记下的作息。` | 还没数出来——这一刻不是「没有」，是还没读到 |
| `还没有记录。` | 一条都还没记到过 |
| `已经打开了，还没记到东西。` | 开关是开的，但还没凑够能记下的动作 |
| `已记录 N 条。` | 已经记下 N 条 |

> 说明一句：上面这行 `已经打开了，还没记到东西。` 是第 15 轮在设备上**真实读到**的——当时刚装好、开关是开的，但时间还短。它和 `还没有记录。` 的区别在于「开关开没开」，不是「好还是坏」。

> 再说明一句：`正在看这台手机记下的作息。` 是第 90 轮补进来的第四种。它和 `还没有记录。` **不是一回事**——`还没有记录。` 是**数过了**，库里确实一条都没有；`正在看这台手机记下的作息。` 是**还没数完**。刚进这一页的那一瞬间还没读到数据库，这时候屏幕上不能写「还没有记录」，那等于替数据库提前下结论，等条数读回来它又跳成别的，看着像是数据丢了。这一种怎么验的、为什么设备层探针抓不到它，都写在 `docs/06` 第 3.66 节里。

下面是**`按我的作息说话`**这一行开关，再下面是随开关变的说明字：

- **开着的时候**：`记的是手机什么时候亮屏、解锁、插电。常伴活着的时候才记得下来——从后台把它划掉之后，那段时间的动作就记不到了。`
- **关着的时候**：`没有打开。常伴照样能用，只是说话的时机按普通人的作息来猜，可能正好撞上您午睡。`

不管开关开还是关，这两行都常驻：

> `不读您看了哪个应用，也不要额外权限，更不上传。`
> `只保留最近 30 天，过期的会自动删掉。`

这两句是这一版最实在的两句承诺，都是真的：应用**一个权限都没申请**，也没有后台自启的组件（`records/03` 的 ADR-009、`records/02` 的 RC-008）。「常伴活着的时候才记得下来」那句也不是免责话，是事实——从后台划掉之后它就真的记不到了。

底下有 **`清空作息数据`**。点了先弹一个框，问 **`确定要清空吗？`**，正文写：

> 已经记下的作息记录会全部删掉，作息画像也会一起清空。这一步不能撤销。

两个按钮是 **`清空`** 和 **`不清了`**。选「不清了」就当没点过。

### 5.4 说话的时机

这一块的**`说话的时机`**行会显示它现在怎么决定跟您说话的时间，一共**六种**样子：

| 屏幕上的话 | 什么时候出现 |
| --- | --- |
| `正在看您最近的作息。` | 正在算 |
| `按您自己的作息：……，是从最近 N 天的记录里看出来的。` | 数据够了，采集开着，已经按您的作息来 |
| `以前记下的作息：……，是从最近 N 天的记录里看出来的。` | 数据够了，但采集开关关着——这一份只报「记过」，不再参与决定说话的时机 |
| `作息还在了解中：已经看了 N 天，满 3 天就能用上。` | 数据还不够，采集开着 |
| `作息还在了解中：已经看了 N 天。采集没有打开，这份记录先放着，不用它说话。` | 数据还不够，且采集开关关着 |
| `这段时间的作息不太固定，先按普通的作息来说话。` | 数据够了但看不出规律 |

上面第 3 句和第 5 句（`以前记下的作息：…` 与 `作息还在了解中：…这份记录先放着…`）都是**第 89 轮才加进代码的**，第 15 轮实测时还没有这两句。它们说的是同一件事：那颗 `按我的作息说话` 关掉之后，这一行不再按您记下的作息说话。关着的时候，这一行下面还会多出一句说明：

> `采集没有打开，上面这些是以前记下的。以后说话的时机就按普通的作息来。`

照实说一句边界：**这一整段话是第 89 轮才真的做到的。** 在那之前，关掉那颗开关只让「采集」停下来，界面却会说「以后说话的时机就按普通的作息来」，而代码里根本没有改——说话时机的判定仍然在用以前记下的那份作息。那句话当时是**一张空头支票**（由来见 `docs/03` 的 8.52 节）。

第 15 轮实测命中的是第三句：

> `作息还在了解中：已经看了 0 天，满 3 天就能用上。`

**「满 3 天」这一条是真的门槛**：这个数字在代码里叫 `requiredDays`，值是 3。也就是说，刚装上用头两天，它按「普通人的作息」跟您说话；凑够 3 天之后才开始按您的作息来。这个门槛是刻意的——样本太少就下结论，猜错了反倒吵人。

下面一行写着您现在实际被打扰的频率，实测读到的是：

> `现在打招呼的间隔：30 分钟`

这一行的数字不是固定的，是跟着您接话多少自己变的。页上也明说了：

> 它打招呼的间隔会随您接话的多少自己调整：接话少就往后放，最多一天一次。不会越叫越勤。

这一句里的 **`最多一天一次`** 是这一版最硬的承诺之一，代码里叫 `maxGapMinutes = 1440`（`docs/07` 的风险台账里也记着）。**这个方向只有往上放，没有往下收**：您越不理它，它越安静，不会反过来越叫越勤。退避的档位是一步一步拉开的（30 分钟 → 3.5 小时 → 6.5 小时 → …… → 24 小时）。

**这页上还给「它越来越安静」这件事留了一条回头路。** 只要您还在，那个数字不会一直往后退 —— 间隔已经被推长过的时候，卡上那行间隔的下面会多出一行字和一颗按钮。实测读到的那行字是：

> `您有一阵子没接着说话，间隔就退到了上面那个数。`

紧跟着那颗按钮是 **`我现在就在这儿`**。按下去，上面那行数字**当场收回最短那一档**，页面上留一句回执：

> `好，间隔回到最短了。`

**这句回执只报「间隔回到最短」这一件已经发生的事，不承诺「现在马上就来搭话」**：紧接着的那次判定仍可能因为安静时段或别的原因先不说话。

照实说一句边界：这一行与这颗按钮**只在间隔已经被推长过**（连续几次没接话）的时候才出现；按一下**只影响「间隔」这一个数**，不会清掉您的作息、意愿或别的任何东西。


再往下一段，讲的是**您自己下的那条安静指令**。首页那个 **`今天先安静一会儿`** 按下去之后，这一块会多出一行，实测读到的是：

> `今天您说过先安静一会儿，我不迎上来说话。明天起就回到上面那套时机。`

这一行说得很直白：今天它不再主动迎上来说话，但**上面那套时机并没有被改掉**，明天一到就照旧。也就是说，这条指令**只管今天这一天**——不会因为您今天不想说话，就把往后的节奏一起压低。

紧跟着下面有一颗 **`取消今天的安静`**。按下它，上面那一行收起来，页面上留一句回执：

> `好，今天的安静已经取消。`

**这句回执只报「安静取消了」这一件已经发生的事，不承诺「现在马上就来搭话」。** 取消只是让上面那套时机重新管事，它什么时候真来，仍按那套间隔算。

照实说一句边界：这一块是在**进到这一页那一刻**读的「今天」。今天是什么日子，是在您打开这一页的瞬间定下的——**停在这一页跨过午夜，它不会自己变样**，要退出去再进来一次才会按新的一天重算。

### 5.5 关于常伴

**`关于常伴`** 这一块列的是这个应用的本分：

> `版本 0.1.0`
> `不联网上传您的任何内容。`
> `没有广告，没有积分，没有要每天完成的任务。`
> `您的称呼、字号这些设置只存在这台手机里。卸载应用时它们会一起消失，我们这边不会留有副本。`

这几句里，`不联网上传您的任何内容` 和 `卸载应用时它们会一起消失` 都能验证：应用清单里没有任何联网相关之外的权限被用来自动传数据（事实上它一个权限都没要），所有内容都写在手机本地的数据库里（`records/04`、ADR-009）。

> 提醒一句：`没有积分` 里的「积分」两个字，是界面上原样这么写的（在这个句子里它是「否定」的意思）。手册这一节照抄屏幕，没有别的意思。

### 5.6 重新来一遍

这一块从**第 47 轮**起有**两行**：上面那行是只读的，下面那行才会真清。

**上面那行**，说明写着：

> 只是重新看一遍，称呼、字号和作息设置都不会变。

按钮是 **`再看一遍开头那几页`**。点它**不弹任何确认框**，直接进第 1 节讲的那三页引导，原样再放一遍。它**一个字节都不写**：称呼、字号、作息、说话的时机全都不变，也没有任何东西被清掉。

重看和第一次进来只有两点不同，而且都是为了「重看」才有的：

| 不同 | 第一次 | 重看 |
| --- | --- | --- |
| 第 2 页 | 能填称呼、能选字号 | 两处都**点不动**，页首多一句 **`这一页只是让您再看一遍。这里改不了，要改请回设置页。`** |
| 第 3 页 | 两个按钮 **`可以，按我的作息来`** / **`先不用`** | 只剩一个 **`看完了`**；末尾那句也从「两个按钮都能选……」换成 **`这一步当时已经问过您了。以后在设置里随时能改，也能一键把记下的东西全删掉。`** |

这三页上的**字**，重看和第一次看到的是同一批句子，一个字都没改。重看时左上角的返回箭头照旧有效（第 3 页往回走一步回第 2 页，再往回走就退出重看、回设置页）。

**下面那行**才是真清。这张卡叫 **`重新来一遍`**，里面依次是：先说一行**现在的存量**——`现在存着：您说过的意愿 N 条，记下的日常 N 条，作息记录 N 条。`（三个数是数据库里的真实条数，清完立刻变 0），再是说明：

刚进这一页、三个数还没数出来那一瞬间，这一行先写的是 `正在数这台手机里存着的东西，稍等一下。`，等数从库里读回来才换成上面那句存量。**不会先抖一个「0 条」出来**——先显零再往上跳，看着像是东西丢了。

> 会把称呼、字号、作息记录、您说过的意愿、记下的日常，还有说话的时机一起清回初始状态，然后重新显示第一次打开时的说明。

最后那颗按钮是 **`清空全部数据`**。点它弹框，标题同样是 **`确定要清空吗？`**，正文是：

> 这台手机上常伴记下的东西会全部清掉：称呼、字号、作息记录、您说过的意愿、记下的日常，还有说话的时机。这一步不能撤销。

再点 **`清空`** 或 **`不清了`**。

注意它说的是「重新显示第一次打开时的说明」——也就是清完之后，会重新走一遍第 1 节讲的那三页引导；那三页因为是清完之后走的，所以还是带输入的「第一次」样子。**这一版起一次就把上面这些全清干净**，不用再单独去点 `清空作息数据`（第 71 轮改的口径，见 `docs/01` 的 AC-14.3）。

### 5.7 这一页没有「确定」按钮

设置页从头到尾**没有**一个总的「保存」或「确定」按钮。改称呼要按「保存称呼」，改字号点一下立刻生效，两个「清空」各有自己的确认框——除此之外，您改完退出去，就已经算数了。

这是刻意的：一页里最怕的就是「我改了但没保存」这种事。这一版让你做完一个动作就有一个动作的反馈（`records/03` 的 ADR-013）。

## 7. 常见问题

**问：它老来跟我说话，怎么让它少说点？**
有两件您自己能做的事，都不用去设置里翻。一是**不搭理它**——它打招呼的间隔是跟着您接话多少变的，接话少就往后放，最多一天一次。二是**明说**：「您自己的节奏」底下第一行 `今天先安静一会儿`，按一下，今天就不再迎上来说话；再按一下（那时那一行写着 `那就说话吧`）就改回来（§2.6）。这两件事它是分开算的：**您自己按下的静音不算「您不理它」**，不会把下回说话的间隔往后推。还有一点要分清：静音管的是「它迎上来说话」这一件事，您主动去说两句、去玩一会儿、去翻设置，它照旧陪着。它在这一条上的边界写在 §8.10。

**问：我明明记得它刚才还跟我打招呼，怎么现在不吭声了？**
有两种可能。一是它觉得「这会儿该安静」（比如午睡时段），安静的时候它是真的不说话；二是它判断刚刚才说过、还没到时候（叫「太近了」）。这两种时候它顶上那行字会自己换，您可以留意一下——不会出现「它想说但憋着还留个半句」这种事（`ui/home/InterventionVoice.kt` 里两个安静分支压根不读您记下的事，理由写在源码注释里）。

**问：我玩一局它记下来了吗？换手机还有吗？**
没有，换了手机也没有。玩一局不会往手机里写任何东西，结束卡上写的就是这句 `这一局只在屏幕上，关掉就没了。`（`records/04` 有对应的设备验证）。同理，称呼、字号这些设置也只在您这台手机里，换手机要重新设一次。

**问：它到底把我的东西存在哪？**
就在这台手机上，应用的本地数据库和本地设置文件里。它不上传、没有账号、没有云端（`records/03` ADR-009）。卸载应用时这些会一起没了，我们这边不会留有副本——这句话是设置页「关于常伴」里原样写的，也是真的。

**问：我想把记下的东西删干净怎么办？**
分两处：您自己的作息记录，去设置页点 `清空作息数据`；您说过的、它记住的事，在首页下方「常伴记住的事」里有一条一条删的按钮，也有 `全部清空`。两处都能把内容真的删掉，删了不能撤销。

**问：怎么让它变得像从没装过一样？**
去设置页点 `清空全部数据` → 确认 `清空`。这会把称呼、字号、作息记录、您说过的意愿、记下的日常，还有说话的时机一起清回初始状态，并重新显示第一次打开的那三页说明，一次清干净——不用再单独点 `清空作息数据`。最彻底的做法是卸载应用——那连数据库文件都一起没了。

　**但要是您只是想再看一遍那三页、并不想丢掉设置**，那就别点这一颗：同一块里上面还有一颗只读的 `再看一遍开头那几页`，点它就把三页重放一遍，称呼、字号、作息都不动（见 §5.6）。

## 8. 做不到的事（诚实清单）

这一节是这本手册里最该看的一节。上面讲的都是「它是什么样」，这一节讲的是「上面这些我们还不能替它担保到什么程度」。凡是在这一节里的，都请当成「还没证实」，而不是「已经没问题」。

### 8.1 从未有真人用过它

**这一版从头到尾没有一位真人试过。** 上面所有「实测」都指的是在模拟器里由脚本操作得到的观察，不是 55–65 岁的人拿在手里用出来的结果。字号是不是真的够大、话是不是真的一句就懂、第一次打开会不会懵——这些**全都还没有答案**。

这件事不是我们忘了，是清单上明确欠着的账：`docs/07` 的风险台账里编号 **R-09** 是**红色**等级的那一条，写的正是这个。这本手册是它对 R-09 承诺的一次兑现——用一份把话说清楚的说明来减轻风险——但**唯一能真正关闭它的路径是真人试用，而那还没有发生**（`docs/07:640` 有承诺的原文）。

### 8.2 中文打字没有被真实输入法验过

设置页那个「怎么称呼您」的输入框，程序里是能用中文输入法的。但**测试过程里没有用真实输入法打过中文**：设备脚本只能往输入框里送英文字符（`adb shell input text` 的天然限制），验中文时用的是测试框架直接把字符塞进去的办法，那**不是**用户用拼音或手写打字的样子。

所以「用户用中文输入法输入称呼」这条路，**从头到尾没有被任何人验证过**（`docs/01:485`，GAP-02，长期平台限制）。

第 56 轮补了能补的那一半：设备上也验过「中文称呼存进手机、再从手机里读回来，一个字都不差」——用的是 3 个汉字「熊勇春」（9 个字节），先在屏幕上输入并保存，然后读手机上的存档文件，确认那 9 个字节真的在文件里，再把文件拷一份、重新读一遍，读出来的还是「熊勇春」；另外还做了两个反例，证明这两条检查不是「怎么都算通过」。**没补上的那一半**：上面这些字符是测试框架直接送进输入框的，**不是**用拼音或手写打出来的，所以真实输入法的组合、候选、上屏那一整段仍然没有人走过。

### 8.3 快慢量过一次了，但只在我们电脑上的模拟器里

这件事第 21 轮终于量了一次（此前从第 4 轮欠到第 20 轮都没排上，就是 `docs/01` 里的 GAP-03）：

- **打开要多久**：连开 9 次，每次都是从零开始（不是从后台叫回来的），**0.94 秒到 1.5 秒之间**，中间那一次是 **1.18 秒**。比我们自己定的 2.5 秒宽裕不少。
- **点了以后多久有反应**：大约 **1.2 到 1.5 秒**之后就能点得动。比这再早一点去点，有时会点不动——查明原因是**测试用的模拟器点屏幕这个动作本身有 0.23~0.39 秒的浮动**，不是应用不接受您的点击。
- **滑动会不会卡**：这一条**没法定**。原本要量的「掉帧」说的是首页滑动，可首页和游戏页**一屏就放得下、根本滑不动**；换到设置页去量，同一台模拟器上连中间水平都在每帧 30 毫秒的用时量级，是这个模拟器自己慢，分不清是应用的锅还是模拟器的锅。

**这些数字全部来自我们电脑上的一个 Android 模拟器**（Android 15、屏幕 1080×2400、软件渲染），**不是真手机**。所以上面这几段话只能说明「在我们那儿它不是个慢东西」，**不能代替真机**。如果它在您的旧手机上打开得慢，仍然不在我们的意料之外。

### 8.4 只在一种环境里验过

所有验证都发生在**一个**环境里：

- 一个 Android 模拟器（名字 `Elder_API35`），**Android 15 / API 35**
- 屏幕 1080 × 2400，显示密度 420
- 时区是 **GMT**（这一条解释了一件小事：这轮采集时模拟器显示的是 07:31，所以首页打招呼说「早上好」是对的，不是 bug——同样的时刻在您手机上是当地时间）

**没有在任何真实手机上跑过，没有在 Android 8 / 10 / 12 之类的旧系统上跑过。** 应用声明的最低系统是 Android 8.0（API 26），但 API 26 到 34 之间的样子，谁也没见过。

### 8.9 这本手册自己写反过一句话（第 23 轮改正）

「结束卡上那个 `回去歇会儿`」原先在这里写的是「它的意思是回到**挑选页**」。第 23 轮为了给规则页加一条退路去读代码，顺手核到这一句**写反了**：那个按钮调的是页面自己的返回（`PlayScreen.kt` 里 `FinishedPanel(onLeave = onBack)`），走的是往回退一整层，回到的是**首页**——连挑选页一起收掉。这一版的行为没错，错的是描述它的话。已在 §4.6 改正，并给规则页新加的那条 `换一个游戏` 补上了说明。（**第 48 轮补记**：这里说的那一节从第 48 轮起编号是 **§4.7**——新增了 §4.6「找同类」，它顺延了一节；那一节的字一个没动，上面这句里的「§4.6」记的是它顺延之前的编号。）（**第 144 轮补记**：第 144 轮新增 §4.7「找一个不一样的」，这一节顺延为 **§4.8**。）（**第 148 轮补记**：第 148 轮新增 §4.8「倒着点」，这一节顺延为 **§4.9**。）（**第 158 轮补记**：第 158 轮新增 §4.9「单双数」，这一节顺延为 **§4.10**。）

### 8.10 「今天先安静一会儿」：我们自己点过，但没人替您试过

§2.6 那一行是第 60 轮新加的。它的边界在这里。

**一、没有任何真人试用过它。** 第 60 轮收尾在模拟器上**真点过**一次：点之前那一行在「设置」上面，手指落在它的文字中心，当场改口成「好，那就先安静一会儿。」，行变成「那就说话吧」；同一跑还把应用私有目录里的设置文件原样读回来核了一遍——点之后文件里真的多了当天的 `quiet_day`（值等于设备当天的 epoch day），再点一次，文件回到与点之前**逐字节相同**的内容（`build/r60/tap60.txt`，`RESULT=PASS`）。也就是说「按下去有反应」「只管当天」「能改回来」这三件在设备上是有据的。**但点它的是做这个东西的人**：他知道那里有一行、知道要按什么。55~65 岁的人会不会发现这一行、按下去会不会担心「按坏了怎么退」，没有答案。

**二、跨过午夜它不自己重判。** 静音记的是「哪一天」，不是「要不要安静」（`records/03` ADR-055）。这个应用本来就有一条口径：同一次露面不重算。所以要是它一直开着跨过了午夜，首页可能还留着「好，那就先安静一会儿。」，要等下一次露面（切出去再进来、或者重开）才会按新的那一天算。本版本不修，如实记在这里。另外，您改手机的日期也会让它提前或延后失效。设置页那一半是同一个口径：它是在进到那一页那一刻读的「今天」，停在那一页跨过午夜也不会自己变样（这段边界写在 §5.4 末尾）。

**三、它只管首页那一次「迎上来说话」。** 设置页、「跟常伴说两句」、「玩一会儿」都不受影响。安静的是招呼，不是这个应用。

**四、今天是不是静音了，首页和设置页两处都看得到，也都能改。** 这一条是第 76 轮定的新口径 —— ADR-055 第二条决定当初写的是不做第二处（`records/03`），第 76 轮把它推翻了。设置页那张卡上，今天正处在安静里时会多出一行 `今天您说过先安静一会儿，我不迎上来说话。明天起就回到上面那套时机。`，下面跟一颗 `取消今天的安静`，按下之后页面上留一句回执 `好，今天的安静已经取消。` —— 这三句的来龙去脉写在 §5.4 末尾。第 60 轮当时担心：同一件事能在两处改，就会出现「到底哪个是真的」。这个担心没有发生：两处写的是同一份设置存储里的**同一个当天记号**，判断「今天静不静」走的也是**同一条判据**，不存在两份状态要互相对齐，也没有先改哪一边的问题。剩下的边界照实写：回执只报「安静取消了」这一件已经发生的事，不承诺「现在马上就来搭话」；撤销只撤掉您自己下的那条理由，作息、意愿、间隔一个都不动。

## 10. 一页速查对照卡

把它当成贴在冰箱上的一张纸，全篇最要紧的都在这里。

**它是谁**：一个不催您、不评价您、不赚钱的陪伴应用。名字叫「常伴」，版本 0.1.0。

**四页**：引导（3 页，只在第一次看）→ 首页（它在这儿迎上来说话）→ 玩一会儿（八个游戏）→ 设置。就是这么四个地方。

**最要紧的七条**

1. **它绝不会自己跳出来。** 只有您打开应用，它才会说话。没有通知栏消息，一个都没有。
2. **它一分钟都不敢多要您的权限。** 一个权限都没有申请。
3. **它不联网。** 您说的、您玩的，都在这台手机里。
4. **您越不理它，它越安静。** 最多一天一次；不会越叫越勤。
5. **它不装懂。** 听不明白就说听不明白，不会换个话题接着聊。
6. **它不催、不评分、不留成绩。** 游戏玩完就没了；没有打卡、没有积分、没有等级。
7. **它记什么由您说了算。** 它说的事要不要记下来，每次都先问您；记下了也随时能删。

**您可能想做的几件事**

| 想做 | 怎么做 |
| --- | --- |
| 改它叫您的名字 | 设置 → `怎么称呼您` → 填 → `保存称呼` |
| 把字变大 | 设置 → `字的大小` → 点 `更大` |
| 让它别按您的作息说话 | 设置 → 关掉 `按我的作息说话` |
| 删掉作息记录 | 设置 → `清空作息数据` → `清空` |
| 删掉它记住的事 | 首页 → 下方「常伴记住的事」→ 逐条删，或 `全部清空` |
| 再看一遍开头那三页（不改任何设置） | 设置 → `再看一遍开头那几页` |
| 变回刚装好的样子 | 设置 → `清空全部数据` → `清空` |
| 玩一会儿 | 首页 → `玩一会儿` → 挑一个 |

**三件现在还做不到的事（请务必知道）**

- **没有真人用过它。** 上面所有「实测」都是在模拟器里由脚本操作得到的，不是真人在手机上用出来的。
- **只有在一种 Android 环境里验过**（Android 15 模拟器），旧手机、老系统上什么样子，还没人知道。
- **两处旧毛病都修好了**：第一页引导给读屏软件的说明 **第 18 轮**补上了（三页引导的表头都成了标题，各带一句不显示在屏幕上的「第 N 页，共 3 页」）；做完一步的祝贺话里那个双句号 **第 16 轮**修好了（`build/screens16.log:172`）。**而且本轮新增一句实话**：第 18 轮验的是**语义树**（Compose 语义树＋平台层 `AccessibilityNodeInfo`），**没有人真用耳朵听过** TalkBack 念成什么调子。
